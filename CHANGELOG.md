# Functional updates / 功能更新

[Official changelog / 官网更新日志](https://bioseeki.com/changelog) · [Download / 下载](https://bioseeki.com/download)

## 0.1.7 · 2026-10-21

- **科研环境准备：**在工作台检查分析环境，按提示准备任务需要的工具与依赖。
  Check the scientific environment from the workspace and prepare the tools needed for an analysis.
- **任务继续：**更清楚地展示任务进展、需要补充的信息与下一步操作，方便接着推进已有工作。
  See task progress, missing information and the next action more clearly when continuing work.
- **夜间记忆：**改进定期整理与候选记忆的展示，方便查看、核对和管理课题中积累的背景。
  Review consolidation results and candidate memories, and manage the context accumulated in a project.
- **文献雷达：**改进文献匹配、日报与周报，让新增文献及检索状态更容易查看。
  Improve literature matching and daily and weekly digests, with clearer retrieval status.
- **实验记录：**完善记录附件与 Word、PDF 导出，改进中文内容和附件链接的呈现。
  Improve experimental-record attachments and Word/PDF export, including Chinese text and attachment links.
- **引用核对：**改进论断与来源的关联检查，让需要进一步核对的引用更容易识别。
  Improve checks between claims and sources so citations needing review are easier to identify.

## 0.1.3 · 2026-10-17

- **安装到应用程序：**从 DMG 首次打开后，可按提示安装到「应用程序」，完成后自动打开。
  On the first launch from the DMG, install into Applications and open the installed app automatically.
- **替换与后续启动：**替换已有版本前单独确认；从「应用程序」正常启动时跳过安装引导。
  Confirm replacement of an existing app; subsequent launches from Applications skip the installation guide.
