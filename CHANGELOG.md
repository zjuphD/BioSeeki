# Release notes / 版本记录

## 0.1.3 · 2026-10-17

**macOS installation guide / macOS 安装引导**

- First launch from the disk image offers installation into Applications and opens the installed app automatically.
- Replacing an existing stopped app requires confirmation. An already running installation can be opened without overwriting it.
- Subsequent launches of the installed app skip the installation guide.
- The Mac Beta is Developer ID signed and Apple-notarized.

首次从 DMG 打开时，可以按提示安装到「应用程序」并自动打开；替换旧版前会单独确认，后续正常启动不再显示安装引导。Mac Beta 已签名并通过 Apple 公证。
