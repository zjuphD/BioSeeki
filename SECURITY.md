# Security contact / 安全联系

Please report suspected security vulnerabilities privately to **[support@bioseeki.com](mailto:support@bioseeki.com)** with “Security” in the subject.

Include the app version, platform, affected feature, and a minimal description of how to reproduce the issue. Do not send passwords, access tokens, or private research data. Please avoid public Issues for an unaddressed vulnerability.

本仓库为公开产品仓库。疑似安全漏洞请私下发送至 **support@bioseeki.com**，主题注明「安全问题」，提供版本、平台和最小复现步骤。请勿在邮件或公开 Issue 中附带密码、访问令牌和课题隐私数据。
