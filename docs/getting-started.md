# Getting started with BioSeeki

[简体中文](getting-started.zh-CN.md) · [Back to the product overview](../README.md)

## Install and sign in

Download the Mac Beta from **[bioseeki.com/download](https://bioseeki.com/download)**. The public package supports Apple silicon and macOS 14 or later.

Open the DMG, double-click **BioSeeki Beta**, and follow **Install to Applications**. It opens when installation is complete. Afterwards, launch it from Finder → Applications. Dragging the app into Applications also works.

Sign in with a BioSeeki account. If you need an account, use the registration link in the sign-in flow. Plan availability and current terms are on the official website.

## Choose a project, then add the material

Use a project to keep related conversations, papers, data, and outputs together. Open **Project materials / 课题资料** to collect existing papers and records, or attach a file to the conversation when asking about it.

Begin with the actual question and the material needed to answer it. For a dataset, include sample groups and units. For a paper, include the PDF and the figure or claim you want to understand. For a sequence task, include the vector, insert, and design constraints.

## Read a paper and compare translations

1. Open a PDF in the literature reader from the tool panel, or ask BioSeeki to open it for reading.
2. Use the reader’s translation and comparison controls to view the original alongside the translation. Specify the passage, page, or figure you need help with.
3. Ask for the evidence and its source location, then check the cited passage in the PDF.

**Try:** “Open this PDF for bilingual reading. Explain Figure 2 and show the passages supporting its conclusion.”

The exact reader controls can vary with the document and app version. Translation of one PDF and comparing two different PDFs are separate reading tasks; say which you need.

## Analyze a dataset

Attach the data and sample-group information. State the experimental unit, comparisons, and requested outputs. Ask BioSeeki to check missing values and grouping before proceeding.

**Try:** “Inspect these columns and groups first. Explain the proposed analysis, then return a results table, figures, and the script needed to reproduce them.”

Review the actual result files, analysis conditions, and figures together. A plotted difference is not by itself evidence of statistical significance.

## Work with a sequence in GeneCode

Open **GeneCode**, import or open the sequence, and use the sequence/map views to inspect features and translation. When asking BioSeeki about a particular sequence, use **Associate current sequence with this conversation / 关联当前序列到本会话** so the conversation refers to the intended document.

**Try:** “Check the vector and insert junctions and reading frame. Show the proposed cloning design and list what still needs confirmation.”

## Develop a manuscript or presentation

Start from the paper, figures, results table, and intended audience. Ask for the structure first, then the draft or editable slides with sources.

**Try:** “Use these results for a 10-minute lab meeting. Keep observations separate from interpretations and include speaker notes and sources.”

## Updates and help

- Use the account menu in the lower-left corner → **Check for updates / 检查更新**. Newer releases can also appear next to the notification bell.
- Update reminders open the official installer; you choose when to install.
- [Release notes](https://github.com/zjuphD/BioSeeki/releases) · [Report a problem](https://github.com/zjuphD/BioSeeki/issues) · [Private support](mailto:support@bioseeki.com).

See the official [privacy policy](https://bioseeki.com/privacy) and [terms](https://bioseeki.com/terms) for service and data-handling details. This public repository does not collect research files for analysis.
