# Feedback and documentation

Thank you for helping improve BioSeeki.

- Use **Issues** for reproducible product problems and feature suggestions.
- Use **Discussions** for usage questions and sharing research workflows.
- Documentation corrections and clearer, anonymized examples are welcome as pull requests.

This is a public product hub, not the application source repository. Keep submissions focused on public documentation and product feedback. Do not attach credentials, private account details, or unpublished research data.

For private support, contact [support@bioseeki.com](mailto:support@bioseeki.com). Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

## 中文

问题反馈和功能建议请使用 Issues；使用交流与科研场景分享请使用 Discussions。欢迎通过 PR 修正文档和补充脱敏示例。

本仓库不托管应用核心源码。公开提交请聚焦文档与产品反馈，避免上传账号信息、密钥或未公开课题数据。需要私下处理的问题请联系 [support@bioseeki.com](mailto:support@bioseeki.com)。
